# Multi-dataspace operation

Since chart 11.0.0 the DCP controlplane of fdsc-edc runs as participant contexts: one connector
takes part in several dataspaces, each through its own DSP profiles. Until this guide is complete,
see the [11.0.0 release notes](release-notes/11-x.md#1100--fdsc-edc-200-multi-dataspace-controlplane-dcp)
and the upstream
[multi-dataspace guide](https://github.com/SEAMWARE/fdsc-edc/blob/2.1.0/docs/multi-dataspace.md).
